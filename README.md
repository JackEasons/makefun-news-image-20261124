33 stories on a single front page of THE WORLD TODAY. The lead is the
Hanoi hot pot eatery gas blast (6 killed, 10+ in intensive care), next to
Shenzhou 24 launching with Pakistan's first astronaut and Huawei convicted
on 10 of 12 counts — plus 30 more stories, with a world map, a big-number
strip, region counts, and a DATE CHECK bar. Every story and its outlet are
listed in STORIES.md.

## Run it

```sh
python3 draw24.py
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` only copies the pre-rendered `entry.png` to the output path;
it never renders and never writes to the repository directory.
